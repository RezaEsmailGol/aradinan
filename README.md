# Keshmesh

Keshmesh is a local-first Chrome extension for safer browsing, visual content protection, parental controls, and digital wellbeing.

## Privacy-first design

Keshmesh processes website URLs, visible page text, and image pixels locally in the browser to provide its core protection features. Keshmesh does **not** send page content, image pixels, PINs, local visual hashes, or browsing reports to a Keshmesh classification server.

- Privacy Policy (English): [Keshmesh Privacy Policy](./keshmesh/privacy-policy.md)
- سیاست حریم خصوصی فارسی: [سیاست حریم خصوصی کشمش](./keshmesh/privacy-policy-fa.md)

## Limited Use disclosure

Keshmesh uses website and browsing data only to provide the user-facing safe-browsing, visual protection, parental-control, and digital-wellbeing features described in the extension. Keshmesh does not sell user data, does not use browsing content for advertising, and does not use it for unrelated profiling.
