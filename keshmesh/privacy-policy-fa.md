# سیاست حریم خصوصی کشمش

**تاریخ اجرا:** ۳۰ اوت ۲۰۲۶  
**محصول:** افزونه Chrome کشمش

کشمش با رویکرد Local-first برای مرور امن، محافظت محتوای تصویری، کنترل والدین و Digital Wellbeing طراحی شده است.

## ۱. کشمش چه داده‌هایی را پردازش می‌کند؟

برای ارائه قابلیت‌های اصلی، کشمش ممکن است موارد زیر را فقط داخل مرورگر کاربر پردازش کند:

- دامنه‌ها و URLهای وب‌سایت‌هایی که کاربر باز می‌کند.
- متن قابل مشاهده صفحه، عنوان، metadata و متن اطراف تصاویر برای طبقه‌بندی محتوا.
- پیکسل تصاویر و در صورت پشتیبانی، فریم‌های تصویری مورد استفاده Visual Guard.
- URL تصویر، زمانی که افزونه برای تحلیل محلی نیاز دارد فایل تصویر را از منبع اصلی آن دریافت کند.
- هش ادراکی محلی تصاویر، verdict و امتیاز تشخیص.
- Allowlist، Blocklist، کلمات حساس سفارشی، پروفایل‌ها، زمان‌بندی و تنظیمات محافظت.
- رویدادهای محلی محافظت مانند دامنه، دلیل، زمان و امتیاز محلی یک مورد مسدود یا Blur شده.
- وضعیت کنترل والدین. PIN والد به‌صورت متن ساده ذخیره نمی‌شود و فقط Salted Cryptographic Hash آن برای اعتبارسنجی محلی نگهداری می‌شود.

محتوای وب و سابقه مرور در سیاست Chrome Web Store جزو داده‌های حساس محسوب می‌شوند. کشمش این اطلاعات را فقط برای قابلیت‌های مرور امن و محافظت محتوا که کاربر افزونه را برای آن نصب کرده است پردازش می‌کند.

## ۲. پردازش محلی و انتقال داده

طبقه‌بندی محتوا روی دستگاه کاربر انجام می‌شود. کشمش متن صفحه، پیکسل تصویر، هش ادراکی تصویر، PIN والد یا گزارش‌های مرور را برای یک سرور طبقه‌بندی متعلق به کشمش ارسال نمی‌کند.

برای برخی تصاویر Cross-Origin که مستقیماً توسط Content Script قابل خواندن نیستند، Service Worker افزونه ممکن است همان URL اصلی تصویر را از وب‌سایت یا CDN آن دریافت کند تا تحلیل تصویر روی دستگاه انجام شود. این درخواست به منبع اصلی همان تصویر ارسال می‌شود، نه به سرور تحلیل کشمش.

افزونه کشمش شامل SDK تبلیغاتی یا Analytics نیست.

## ۳. نحوه استفاده از داده‌ها

اطلاعات پردازش‌شده فقط برای امکانات قابل مشاهده کاربر استفاده می‌شوند، از جمله:

- مسدودکردن دامنه‌های شناخته‌شده یا انتخاب‌شده توسط کاربر.
- تشخیص متن یا تصویر حساس.
- Blur، نمایش هشدار یا مسدودسازی صفحه طبق Policy انتخابی.
- به‌خاطر سپردن تصمیم «مجاز/حساس» برای تصاویر در دیتابیس محلی.
- اجرای Schedule، Profile، Parent Lock، Temporary Unlock، Commitment و Cooling-off.
- نمایش گزارش‌ها و Diagnostics محلی.

کشمش از محتوای مرور برای تبلیغات، ساخت پروفایل بازاریابی، فروش داده یا اهداف نامرتبط با قابلیت اصلی افزونه استفاده نمی‌کند.

## ۴. اشتراک‌گذاری یا فروش داده

کشمش اطلاعات کاربر را نمی‌فروشد. محتوای صفحات، تاریخچه مرور، پیکسل تصاویر، اطلاعات PIN و Verdictهای محلی به تبلیغ‌دهندگان، Data Brokerها یا اشخاص ثالث نامرتبط منتقل نمی‌شوند.

## ۵. ذخیره‌سازی و مدت نگهداری

تنظیمات و گزارش‌ها در Chrome extension local storage و Verdictهای تصویری در IndexedDB اختصاصی افزونه ذخیره می‌شوند. دیتابیس تصویر نسخه اصلی عکس را ذخیره نمی‌کند و فقط Hash و metadata لازم را نگهداری می‌کند.

Verdictهای خودکار طبق مدت Cache تنظیم‌شده می‌توانند منقضی شوند. تصمیم‌های دستی ممکن است تا زمانی که کاربر آن‌ها را حذف کند باقی بمانند. سایر داده‌های محلی تا زمان پاک‌کردن، Reset کشمش، حذف افزونه یا پاک‌شدن Storage افزونه توسط مرورگر نگهداری می‌شوند.

## ۶. امنیت

کشمش از جداسازی امنیتی افزونه‌های Chrome و Storage محلی مرورگر استفاده می‌کند. PIN والد به‌صورت Salted Hash نگهداری می‌شود و متن اصلی PIN ذخیره نمی‌شود. با این حال کاربر باید از پروفایل Chrome و حساب سیستم‌عامل خود نیز محافظت کند.

## ۷. کنترل‌های کاربر

کاربر می‌تواند:

- در صورت مجازبودن Policy فعلی، Protection را فعال یا غیرفعال کند.
- Allowlist و Blocklist را مدیریت کند.
- گزارش‌های محلی را مشاهده یا پاک کند.
- Settings را Export/Import کند.
- دیتابیس Visual Verdict را Export/Import/Clear کند.
- کشمش را Reset کند.
- در Chrome شخصی و unmanaged افزونه را حذف کند.

در Chrome Managed، مدیر سیستم می‌تواند کشمش را با Chrome Enterprise Policy به‌صورت Force Installed نصب کند؛ در این حالت نصب/حذف تحت کنترل مدیر سیستم است.

## ۸. استفاده کودکان و کنترل والدین

کشمش قابلیت اختیاری Parent Lock دارد. برای استفاده کودک نیازی به ایجاد حساب کاربری نیست و محتوای مرور کودک برای طبقه‌بندی به سرور کشمش ارسال نمی‌شود. والد یا مدیر دستگاه مسئول انتخاب تنظیمات مناسب است.

## ۹. تعهد Limited Use در Chrome Web Store

استفاده کشمش از اطلاعات دریافت‌شده از Chrome APIs مطابق Chrome Web Store User Data Policy و Limited Use requirements است. داده مرور و محتوای سایت فقط برای ارائه قابلیت‌های محافظتی توضیح‌داده‌شده در محصول استفاده می‌شود و برای تبلیغات شخصی‌سازی‌شده، پروفایل‌سازی نامرتبط یا فروش به اشخاص ثالث انتقال داده نمی‌شود.

## ۱۰. تغییرات این سیاست

در صورت تغییر اساسی در شیوه پردازش داده، این سند قبل یا همزمان با انتشار نسخه مربوطه به‌روز می‌شود و تاریخ ابتدای سند نیز تغییر خواهد کرد.
